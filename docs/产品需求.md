# 识谱助手 · Android 0.3版

## 已确认

- 目标：可安装安卓应用，中文界面，竖屏单手操作必须保留，支持横屏和键盘缩放。
- 导入图片、PDF、MusicXML/MXL；图片/PDF由内置乐谱识别引擎在本机处理，不上传。
- 第一阶段先练音高，弹对后继续，不强制节拍计时。
- 练习前选择右手、左手、双手；按谱表划分声部并可互换，不能用高低音谱号直接决定左右手。
- 逐音练习、小节练习、范围选择和循环；和弦可依次点齐，适合单手。
- 可移动音域的虚拟钢琴，按键有钢琴音色；默认不直接显示答案键位，可按需提示。
- 识别后可以查看原谱、手动校对音符，再进入练习。
- 乐谱与练习记录保存在本机，无账号，无广告。
- 后续确认：用户希望不依赖电脑；0.2版改为手机内识谱，设备目标Xiaomi15（12GB内存），图片/PDF默认本机处理，0.3版已移除电脑服务。

## 第一版流程

导入 → 本地原谱预览 → 开始手机后台离线识谱 → 识别结果待校对 → 校对 → 选手与范围 → 按顺序练习 → 保存本次记录。

MusicXML/MXL可直接离线导入。内置原创练习可直接使用。图片和PDF不会被伪装成识别成功，也不会替换成演示曲目。

## 竖屏单手规则

主要操作在下半屏；保留宽琴键，显示局部音域；八度切换、键宽切换、自动音域跟随；键盘横向滚动有独立拖动条，避免滑动时误弹。和弦命中的音允许累积，错音不清空已命中的和弦音。

## 后续范围

节奏判定、跟弹伴奏、MIDI键盘、麦克风识音、云同步、原谱精确音符坐标、反复记号展开、装饰音与跨谱表复杂配器的完整支持。
